# 10月24日｜Day 10｜名古屋城市体验日

- 城市 / 区域：名古屋
- 住宿：名古屋站附近
- 主题：工业传统、历史街区与城市夜景

## 主题
名古屋并不只是中转城市，这一天可以把它的工业传统、城郭历史和老商业街串起来，形成一次较完整的城市体验。

## 推荐路线
```text
丰田产业技术纪念馆
→ 名古屋城 / 本丸御殿
→ 金鯱横丁午餐或点心
→ 大须观音
→ 大须商店街
→ 栄 / 久屋大通公园晚餐
```

## 推荐时间安排
```text
09:30  丰田产业技术纪念馆
12:00  金鯱横丁午餐
13:00  名古屋城、本丸御殿
15:30  大须观音与大须商店街
18:00  栄、久屋大通公园
19:00  名古屋特色晚餐
```

## 可安排的景点
- 丰田产业技术纪念馆：展示名古屋制造业发展和丰田集团相关内容
- 名古屋城与本丸御殿：是名古屋最具历史感的地标之一
- 大须观音与大须商店街：适合慢慢逛，能看到更本地的街区氛围
- 栄 / 久屋大通公园：傍晚和夜景适合放松散步
