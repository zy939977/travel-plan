# 10月23日｜Day 9｜高山 → 名古屋（轻松转移日）

- 城市 / 区域：高山 → 名古屋
- 住宿：名古屋站附近
- 主题：从飞驒山区轻松转移到中部大城市

## 主题
从高山出发，顺着 JR 特急 Hida 前往名古屋，完成从山区风景到城市体验的平滑切换。这一天以“轻松转移”为主，不做重型安排。

## 推荐路线
```text
高山酒店退房
→ JR特急 Hida
→ 名古屋站
→ 酒店入住 / 寄存行李
→ 栄
→ 久屋大通公园
→ Oasis 21
→ 名古屋特色晚餐
```

## 推荐时间安排
```text
08:00  高山早餐或最后一次街区散步
09:30  退房、取行李
10:30—11:30  乘 JR 特急 Hida 前往名古屋
13:30—14:30  抵达名古屋、办理入住
16:00  栄与久屋大通公园
17:30  Oasis 21、城市夜景
19:00  名古屋特色晚餐
```

## 适合的体验
- 栄：商业区、地下街、餐厅与夜景
- 久屋大通公园：适合傍晚散步
- Oasis 21：城市空间感很强，适合拍照和放松
- 名古屋小吃：从轻松的晚餐开始体验当地风味

## 住宿建议
建议住在名古屋站附近，方便第二天出发和转乘。

## 说明
这一天的重点不是赶景点，而是把节奏从高山的慢生活切换到名古屋的城市氛围。
