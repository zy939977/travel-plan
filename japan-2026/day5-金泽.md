# 10月19日｜Day 5｜金泽

- 城市 / 区域：金泽
- 住宿：金泽站附近
- 主题：近江町市场、东茶屋街

## 行程
1. 从京都前往金泽
2. 参观近江町市场
3. 逛东茶屋街
4. 晚上在金泽站附近休息

10月19日（Day 5）：市场 + 茶屋街
 
核心逻辑：先远后近，把需要排队的寿司放在早上。
• 上午：京都 → 金泽。抵达后先去酒店寄存行李。
• 午餐：Morimori 寿司（近江町店）。这家店 08:00 就开门，不能预约，且排队很久。建议一到金泽就直奔近江町，赶在11点前吃完，避开午市高峰。‌￼
• 下午：逛近江町市场 → 东茶屋街。市场 9:00-17:00 营业，下午人会少一些。两个地方步行不到 20 分钟，逛完市场直接走过去很顺。‌￼‌￼
• 晚餐：若叶（关东煮）⚠️关键提醒。你安排的 “若叶” 可能是金泽有名的关东煮老店。这家店的定休日是 周一和周二，而 10月19日正好是周一，大概率不营业。建议出发前务必再确认一下，或者准备一个备选餐厅。‌￼
