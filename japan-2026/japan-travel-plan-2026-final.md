# Day 1｜10月15日｜抵达大阪

## 主题

抵达、休息、适应节奏。第一天不建议安排重景点，因为第二天要去 USJ。

## 推荐路线

```text
关西机场 T1
→ 大阪梅田酒店入住
→ Grand Front Osaka
→ Grand Green Osaka
→ 梅田地下街
→ 晚餐
```

## 景点简单介绍

### Grand Front Osaka

大阪站北侧的大型商业综合体，餐厅、生活方式店、品牌店比较集中，适合抵达后的轻松散步。

### Grand Green Osaka

梅田新开发区域，城市感较强，适合傍晚散步和看大阪现代城市界面。

### 梅田地下街

大阪最典型的地下商业系统之一，适合吃饭、逛街、买简单用品。

## 酒店推荐

### 首选区域：大阪梅田

优点：第二天去 USJ 相对方便，第三天去京都方便，餐饮、购物选择多。

推荐酒店：

- Hotel Intergate Osaka Umeda
- Hotel Hankyu RESPIRE Osaka

- Villa Fontaine Grand Osaka-Umeda

## 美食推荐

# Day 3｜10月17日｜大阪 → 京都

## 主题

进入京都，但不走东山线。本日安排伏见稻荷、锦市场、河原町、鸭川与先斗町。

## 推荐路线

```text
大阪退房
→ 京都站寄存行李
→ 伏见稻荷大社
→ 锦市场
→ 河原町
→ 鸭川散步
→ 先斗町晚餐
→ 京都站附近入住
```

## 景点简单介绍

### 伏见稻荷大社

京都代表性千本鸟居景观。不建议完整登顶，走到半山即可获得较完整体验。

### 锦市场

京都食材、小吃、腌菜、茶点和伴手礼集中地，适合作为午餐或下午小吃点。

### 河原町

京都市中心商业区，百货、餐饮、药妆和生活方式店都比较集中。

### 鸭川 / 先斗町

傍晚最舒服。适合晚餐后沿河散步，也适合找小型居酒屋或京料理店。

## 酒店推荐

### 首选区域：京都站附近

优点：后续去金泽方便，行李寄存和转车方便，餐饮选择稳定，避免住进景区拖箱子。

```text

→ 天龙寺
→ 渡月桥
→ 常寂光寺
→ 二尊院
→ 嵯峨鸟居本
→ 返回京都站
```

## 景点简单介绍

### 岚山竹林

京都代表性自然景观之一。建议早上抵达，避开人潮。

### 天龙寺

岚山代表性寺院，庭园值得看，适合与竹林一起安排。

### 渡月桥

岚山地标，适合中午前后散步。

### 常寂光寺

秋季氛围很好，比竹林区域安静，适合慢慢走。

### 二尊院

岚山深处较安静的寺院，可与常寂光寺顺路安排。

### 嵯峨鸟居本

比竹林和渡月桥安静，更有京都老街感，是这天的重点之一。

# Day 5｜10月19日｜京都 → 金泽

## 主题

从京都进入北陆。金泽是本次行程里最舒服的城市之一，节奏比京都慢，城市品质很高。

## 推荐路线

```text
京都
→ 敦贺换乘
→ 金泽
→ 近江町市场
→ 东茶屋街
→ 主计町茶屋街
```

## 景点简单介绍

### 近江町市场

金泽海鲜、甜虾、喉黑鱼和市场餐饮集中地，适合抵达后吃午餐。

### 东茶屋街

金泽最有代表性的传统茶屋街。木格窗町屋、金箔店、传统茶屋和咖啡馆集中。

### 主计町茶屋街

临河、安静，傍晚氛围很好。比东茶屋街游客少，更适合散步。

## 酒店推荐

### 首选区域：金泽站附近

优点：去白川乡巴士方便，城际移动方便，酒店选择多，餐饮和购物不难解决。

# Day 6｜10月20日｜金泽完整一日

## 主题

庭园、城址、当代艺术、武家街区。这是整趟行程里城市体验最舒服的一天之一。

## 推荐路线

```text
兼六园
→ 金泽城公园
→ 21世纪美术馆
→ 长町武家屋敷
→ 尾山神社
→ 香林坊晚餐
```

## 景点简单介绍

### 兼六园

金泽最核心的庭园景点，也是日本代表性庭园之一。适合早上参观。

### 金泽城公园

加贺藩历史中心，与兼六园相邻，可以顺路安排。

### 21世纪美术馆

当代艺术馆，建筑和公共空间本身也很好看。热门展览建议提前确认预约。

### 长町武家屋敷

保留武士住宅街、水渠和土墙，比东茶屋街更生活化。

### 尾山神社

建筑风格独特，适合傍晚前后顺路看。

## 住宿

继续住金泽站附近。

# Day 7｜10月21日｜金泽 → 白川乡 → 高山

## 主题

白川乡一日游，傍晚继续前往高山住宿。这样不用抢白川乡合掌民宿，也能减少住宿不确定性；缺点是看不到白川乡清晨和游客散去后的夜晚。

## 推荐路线

```text
金泽站
→ 白川乡
→ 荻町城迹展望台
→ 合掌村主街
→ 和田家
→ 白川乡巴士站
→ 高山
→ 高山市区入住
```

## 推荐时间安排

```text
08:10左右  金泽站出发
09:30左右  抵达白川乡
10:00  荻町城迹展望台
11:30  合掌村主街散步
12:30  午餐
13:30  和田家 / 明善寺周边
15:30左右  返回白川乡巴士站

17:00左右  抵达高山并入住
18:30  高山市区晚餐
```

具体班次以浓飞巴士和北铁巴士当年秋季时刻为准，建议提前预约 **金泽 → 白川乡** 和 **白川乡 → 高山** 两段。

## 景点简单介绍

### 荻町城迹展望台

白川乡全景最经典的位置。建议抵达后先上展望台，先建立村落空间感。

### 合掌造村落

茅草屋顶民居群，是白川乡核心景观。现在不住白川乡，就把重点放在白天完整游览，不要只拍照打卡。

### 和田家

白川乡代表性合掌造民居之一，适合了解传统建筑内部结构。

## 住宿推荐

### 住宿改为：高山市区

建议连续住 **2晚高山**，10月21日和10月22日都住同一家酒店。这样第二天高山可以完整慢游，也不需要每天换酒店。

# Day 8｜10月22日｜高山完整一日

## 主题

高山完整慢游日。因为前一天已经住进高山，这一天不用早起赶巴士，可以把宫川朝市、老街、高山阵屋和酒藏街慢慢串起来。

## 推荐路线

```text
宫川朝市
→ 高山阵屋
→ 上三之町老街
→ 中桥
→ 酒藏街
→ 飞驒高山美术馆 / 飞驒之里（二选一）
→ 高山市区晚餐
```

## 景点简单介绍

### 宫川朝市

高山最有生活感的早晨路线。适合买当地蔬果、味噌、小吃和手作杂货。

### 高山阵屋

江户时代行政设施，如果对历史感兴趣可以入内；如果只想轻松逛街，也可以只看外围。

### 上三之町老街

高山保存较完整的传统商人街。酒藏、味噌店、工艺店、咖啡馆集中，是高山最核心的街区。

### 中桥

高山市区代表性的红桥，早晨和傍晚拍照都不错。

### 酒藏街

适合试饮清酒、买当地酱油、味噌和小吃。

### 飞驒之里 / 飞驒高山美术馆

下午二选一即可：

- **飞驒之里**：民俗村落，更适合想看传统建筑的人。
- **飞驒高山美术馆**：更轻松，适合天气不好或想减少户外步行时选择。

## 酒店推荐

继续住高山市区同一家酒店，不换酒店。

# 这版行程评价

## 优点

- 京都减少一天，去掉拥挤的东山线
- 金泽、高山保留完整，白川乡改为日游更省心
- 删除高山到伊势志摩的长距离折腾，移动强度明显下降
- 增加名古屋2晚，城市体验、制造业文化与地方美食更丰富
- 高山—北陆地区周游券能够完整覆盖到名古屋，使用更顺
- 最后大阪留2晚，购物更从容
- 不安排神户，也不以温泉为主题

## 缺点

- 从金泽开始仍有连续数日移动，需要提前安排大行李转运
- 名古屋自然景观较少，内容更偏城市、工业、历史与美食
- 10月24日为周六，名古屋站附近酒店价格可能偏高

## 最终路线

```text
大阪
→ 京都
→ 金泽
→ 白川乡（日游）
→ 高山
→ 名古屋
→ 大阪
```

这是目前更顺路、更城市化，也更符合“自然风景 + 城市体验 + 最后集中购物”的版本。
