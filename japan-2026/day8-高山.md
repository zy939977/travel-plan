# 10月22日｜Day 8｜高山

- 城市 / 区域：高山
- 住宿：高山市区
- 主题：高山老街、宫川朝市

## 行程
1. 从白川乡前往高山
2. 逛高山老街
3. 体验宫川朝市
4. 晚上在高山市区休息

| 时间 | 地点 | 安排 |
|---|---|---|
| **07:30** | 酒店 | 起床、早餐 |
| **08:00** | 酒店出发 | 步行前往宫川朝市 |
| **08:15–09:00** | **宫川朝市** | 朝市、当地水果、腌菜、小吃 |
| **09:00–09:20** | 宫川沿岸 → 中桥 | 河边散步、拍照 |
| **09:20–10:05** | **高山阵屋** | 江户时代官府建筑参观 |
| **10:05–11:30** | **三町古街** | 古街、酒藏、商铺、飞驒牛小吃 |
| **11:30–12:40** | **古街附近午餐** | 正式吃一顿飞驒牛 |
| **12:40–14:30** | 三町古街深度慢逛 | 上三之町、上二之町、上一区域 |
| **14:30–15:15** | 咖啡 / 甜品 | 下午休息 |
| **15:15–16:30** | 古街外围 / 宫川沿岸 | 人少后的街道、拍照 |
| **16:30–17:00** | 返回酒店 | 放东西、休息 |
| **17:30以后** | 高山市区 | 晚餐 + 自由散步 |

| 地点 | 简单理解 | 建议停留 | 主要看什么 |
|---|---|---:|---|
| **宫川朝市** | 高山最经典的传统早市 | 45 min | 水果、蔬菜、味噌、腌菜、手工艺 |
| **宫川河岸** | 高山市中心最舒服的散步区域 | 15 min | 河景、桥、传统建筑 |
| **中桥** | 高山标志性的红色桥梁 | 10 min | 红桥＋宫川经典机位 |
| **高山阵屋** | 江户时代幕府在飞驒的行政机关 | 45 min | 官府、住宅、庭院、粮仓 |
| **三町古街** | 高山最核心的传统町屋保护区 | 2–3 h | 木町屋、商铺、酒藏 |
| **上三之町** | 古街中最经典的一条 | 1 h+ | 最典型的高山街景 |
| **酒藏** | 高山传统清酒文化的重要组成 | 随逛 | 杉玉、试饮、日本酒 |
| **飞驒牛料理** | 高山最有代表性的当地美食之一 | 1 h | 午餐安排重点 |

## 说明
高山适合安排古街与早市体验。
